# 🎓 Royal Service International Institute (RSII)

A modern and fully responsive university website built using **HTML, CSS, and JavaScript**. This project showcases a professional educational institution website featuring a clean design, responsive layouts, student testimonials, course information, campus highlights, and modern user experience.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/vivanpatil860-create/decodelabs-vivan-frontend.git
```

### Navigate to the Project Folder

```bash
cd RSII-University-Website
```

### Run the Project

Open `index.html` in your browser or use VS Code Live Server.
